# Security policy

Rustbound Idle is a static, single-player browser game. It has no accounts or game server, and saves stay
in each player's browser. Editing your own save is not a security vulnerability.

Security reports may still involve dependencies, the build and deployment process, the service worker,
or a flaw that affects visitors to the public site.

## Report privately

Use GitHub's [private vulnerability reporting form](https://github.com/journey-to-code-org/rustbound-idle/security/advisories/new).
Please include the affected file or URL, reproduction steps, impact, and any suggested fix. Do not open a
public issue until the maintainers have had a reasonable chance to investigate.

Supported version: the current `main` branch and the public deployment. Frozen tutorial checkpoints are
kept for learning and do not receive backported fixes.
