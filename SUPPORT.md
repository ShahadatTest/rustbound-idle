# Getting help

- Setup question or game idea: use [GitHub Discussions](https://github.com/journey-to-code-org/rustbound-idle/discussions).
- Confirmed bug: open a [bug report](https://github.com/journey-to-code-org/rustbound-idle/issues/new/choose).
- Security concern: use [private vulnerability reporting](https://github.com/journey-to-code-org/rustbound-idle/security/advisories/new).
- Conduct concern: use the private contact route in [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

Please do not send private support requests for ordinary setup problems. Public answers help everyone.
